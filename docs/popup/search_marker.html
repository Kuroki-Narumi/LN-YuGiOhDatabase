リンクマーカー

  • マウス左ボタンを押しながらドラッグすると、通り過ぎた矢印が赤(有効)になります。
  • マウス右ボタンを押しながらドラッグすると、通り過ぎた矢印が灰色(無効)になります。
  • 一つでも赤くした場合、リンクモンスター以外のカードは検索候補から外れます。
  • 「OR」が選ばれている場合、赤にした方向をいずれか一つでも持っていればヒットします。
  • 「AND」が選ばれている場合、赤にした方向全てを持っている場合のみヒットします。
    • 赤にされていない方向を持つ場合もヒットします。
    • 完全一致で検索したい場合は、「AND」を選んだ上でリンク値も指定してください。
