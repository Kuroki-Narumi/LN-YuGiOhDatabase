セルのスタイル

  • 表の各セルに表示される数値の形式を指定します。
  • 「枚数」は枚数をそのまま表示します。
  • 「%(縦)」は表の最上段(トータル行)を100として、各縦列が割合で表記されます。
    • 画像の状態で「%(縦)」を選択した場合、例えば「戦士族-地属性」のセルには
      「全戦士族モンスターのうち、地属性の割合」が%単位で表示されます。
  • 「%(横)」は表の左端(トータル列)を100として、各行(横列)が割合で表記されます。
    • 画像の状態で「%(横)」を選択した場合、例えば「戦士族-地属性」のセルには
      「全地属性モンスターのうち、戦士族の割合」が%単位で表示されます。
