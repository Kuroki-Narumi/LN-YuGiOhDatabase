「タグ管理」タブ

ログ管理などで使われるデッキタグを管理するタブです。
このタブで設定した内容はアプリ設定に記憶され、次回以降の起動時に復元されます。

説明

  1. テキスト検索
    • 任意の文字列を入力してEnterを押すと、「名前」または「検索用文字列」にそれを含む、次の項目が選択されます。
    • 連続してEnterを押すことで、条件に該当するタグを次々に選択できます。
  2. エディットバー
    • ログの編集に関する操作を行うボタン群です。
    • : 最後に行った操作(タグの追加/編集/削除)を元に戻します。
    • : 最後に元に戻した編集操作をやり直します。
      • 元に戻す以外の操作を一度でも行うとやり直しはできなくなります。
    • : 全ての項目を削除してリストを空にします。
    • : .jsonファイルを読み込んで、その内容を反映します。
    • : このデッキの内容を.jsonファイルとして保存します。
  3. タグリスト
    • デッキタグの一覧です。
    • 項目を選ぶとその内容が右の編集エリアに反映されます。
    • ヘッダークリックによるソート機能はありません。
  4. 項目の操作
    • : 編集中のタグを新しくリストに追加し、その項目を選択します。
      • 既に存在する「名前」のタグは追加できません。
      • 既存タグの「検索用文字列」を変更したい場合は、まずそのタグを選択してください。
    • : 編集中の内容を選択中の項目に反映します。
      • 「反映」せずに他のタグを選んだ場合、編集中の内容は破棄されるのでご注意ください。
      • 既に存在する「名前」を指定した場合、選択中の項目は削除され、「検索用文字列」が更新されます。
    • : 選択されている項目を1つ上に移動します。
    • : 選択されている項目を1つ下に移動します。
      • この並び順はタグ選択のポップアップ内での並び順に影響します。
    • : 選択されている項目を削除します。
    • : 全てのタグを、「名前」の辞書順に並べ替えます。
  5. 名前
    • タグ選択のポップアップ内に表示される名前を設定します。
      • 複数のタグが選択されている場合はカンマ,区切りで連結されます。
  6. 検索用文字列
    • タグ選択で検索する際のヒントとなる文字列を指定します。
      • 半角英数および記号のみ指定できます。
      • テキストボックスに何か入力すると、「検索用文字列」にその文字列を含むタグがマッチします。

タグリストのダウンロード

  • デッキタグリストの雛形として、ROKINAが作成したリストを公開しています。
  • 「名前をつけて保存」したら、「タグ管理」タブのボタン、またはタブ内へのドラッグ&ドロップで読み込んでください。
  • タグの内容は作者の『遊戯王マスターデュエル』での対戦履歴から適当に作成したため、テーマの漏れ等がありえますのでご了承ください。
