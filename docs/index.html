Version 2.0.1

遊戯王OCGのカード情報の確認など様々な機能を盛り込んだWindowsアプリです。

機能の例

  • 遊戯王公式データベースで公開されているデータをオフラインで確認・検索
  • 統計>統計表: カードを性質ごとに分けて表で確認
  • デッキ>デッキ編集: デッキリストを作成し画像やテキストで共有
    • 公式データベースの「マイデッキ」との連携も可能
  • デッキ>手札検証: 必要なカードを指定して、初手に引ける確率を確かめる
  • デュエルログ: 勝敗を詳しく保存し、対戦相手の傾向やカードごとの勝率寄与などを分析

注意

  • 起動には.NET Runtime (10.0以上)のインストールが必要です。
  • アプリの設定内容は(ユーザー)/AppData/Local/LivreNoir/YuGiOh/SettingsV2.jsonに保存されます。設定を初期化したい場合はファイルを削除してください。

不明な点や要望があればROKINA(twitter)までご連絡ください。
