「パック」タブ

公式データベースで公開されているカードパックなどを一覧するためのタブです。

説明

  1. サーチバー
    • テキストボックスに入力してEnterを押すと、そのテキストを名前に含むパックで絞り込みます。
      • 全角の英数字や一部記号は自動的に半角化されます。
    • : 検索ウィンドウを開きます。
    • : 絞り込みを解除します。
    • サーチバーの右端には、現在そのリストに表示されている項目の数が表示されます。
  2. パックリスト
    • パック名などが一覧されます。
    • 項目を選択すると右側にパック情報が表示されます。
    • リストの並び順は発売日順で固定されています。
  3. パック情報欄
    • 選択されているパックの詳細が表示されます。
    • 「発売日」は公式データベースでの情報の公開日であり、厳密にはそのパックが発売された日ではない可能性があります。
  4. パックID
    • 公式データベースのURLで確認できる、このパックの固有番号です。
    • TCG(英語版)のパックの場合は末尾にeが付きますが、本来のパックIDは数字のみで構成されています。
      • 末尾のeは本アプリの独自仕様です。
      • 同じIDでも言語によって内容の違うパック(主にトーナメントパック系)があるため、末尾文字により区別するようにしています。
  5. 公式DBリンク
    • 公式データーベースのこのパックの情報ページを開きます。
    • OCG(日本語版)のパックの場合は日本語版のページ、TCG(英語版)のパックの場合は英語版のページが開きます。
  6. カードリスト
    • このパックに収録されているカードの一覧です。
    • カードナンバーが設定されている場合は、カードアイコンの左にそれが表示されます。
    • カード名のリンクをクリックすると「カードリスト」タブに切り替わり、そのカードが選択された状態になります。

検索ウィンドウ

  1. 適用ボタン
    • 設定された条件にてパックリストの検索(絞り込み)を実行します。
  2. クリアボタン
    • 設定されている内容を全て初期化します。
    • 絞り込みを解除したい場合、このボタンを押してから「適用」するか、サーチバーのボタンを押してください。
  3. 閉じるボタン
    • 編集の内容を破棄し、このウィンドウを閉じます。
    • 検索は実行されません。
    • ESCキーを押した際もこのボタンを押した扱いとなります。
  4. 発売日
    • 公式データベースでの情報公開日で絞り込みます。
    • 日付はテキストボックスに直接入力するか、カレンダーボタンを押してカレンダーから選べます。
    • テキストボックス上でマウスホイールを回すと1日ずつ切り替わります。
    • テキストボックス上で右クリックすると各シーズンの開始日を直接選択できます。
  5. ロケール
    • チェックを外すとその版のパックがリストから除外されます。
  6. 文字列検索
    • サーチバーのテキスト欄と同様のテキスト検索を行います。
    • 「正規表現を使用」にチェックを入れると正規表現での検索が可能です。
      • これにチェックが入っている場合、テキストボックスの内容が正しく正規表現として解釈できない場合には枠が赤くなります。
        • 枠が赤い状態で検索を実行した場合、「正規表現を使用」にチェックは入っていない扱いで検索します。
      • 全角の英数字や一部記号は自動的に半角化されます。
