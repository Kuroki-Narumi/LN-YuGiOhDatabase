• Version 2.0.0 (2026/09/16)
    • メジャーバージョンの更新
      • 要求ランタイムを.NET10に変更しました。
      • 旧バージョンとはアプリ設定を含めて完全に非互換です。
      • 実行ファイルの名前をYuGiOh DatabaseからLN-YuGiOhDatabaseに変更しました。
    • 仕様変更
      • ありすぎて作者も把握しきれてないので気合で感じてください。
      • 重要: 文字列検索全般において以下のように変更しました。
        • 検索語句の複数指定ではスペースで区切るようにしました。(旧バージョン: |で区切る)
        • 検索語句を複数指定した場合、デフォルトでは**いずれか1つ以上が含まれれば**ヒットします。
          • 例: ブルー アイズで検索すると「レッドアイズ・ブラックドラゴン」などがヒットします。
        • 語句の前に+を付けると必須扱いになります。
        • 例: ブルー +アイズで検索すると「ブルー」と「アイズ」を両方含むようなカードがヒットします。
        • 例: ブルー レッド +アイズで検索すると「ブルーアイズ」や「レッドアイズ」のようなカードがヒットします。
        • 語句の前に-を付けると除外扱いになります。
        • 例: ブルー -アイズで検索すると「ブルー」を含むが「アイズ」を含まないカードがヒットします。(例: 「ブルー／ポーション」)
    • 機能追加
      • データベース>カードリストにおいて、カード画像の設定ができるようになりました。
        • 右上のCARD IMAGEと書かれたボタンを押すと「ファイルを開く」ダイアログが表示されるので、そのカードに設定したい画像を選んでください。
        • 右クリックメニューから変更や削除ができます。
        • 設定後はカード画像のサムネイルをクリックすると拡大表示します。
      • デュエルログ>統計において、ログの「備考」を検索できるようにしました。

  • Version 1.7.6 (2024/11/30)
    • 機能追加
      • カード名のテキスト検索において、正規表現を使用しない場合に、半角の|で区切ることでOR検索ができるようにしました。
        • 正規表現を使用しない場合、カード名はひらがな/カタカナを区別せずに検索可能です。
        • 例えばてんぱい|さんげんと検索することで、「天盃龍」カードと「燦幻」カードの両方を一度に検索できます(《覚醒の三幻魔》など無関係のカードもヒットします)。
      • ソート及び絞り込みボタンが存在するカードリストにおいて、任意のプリセットをデフォルトに指定できるようにしました。
        • デフォルト指定ボタンをクリックすることで、そのプリセットをデフォルトプリセット扱いにします。
        • Altキーを押しながらデフォルト指定ボタンをクリックすると、デフォルト指定を解除します。
        • デフォルトプリセットの指定は次回以降のアプリ起動時に反映されます。
        • デフォルトに指定されたプリセットは以下のリストに対して適用されます。
          • データベース/カードリストのカードリスト
          • データベース/カードリストにおいて個別に開いたウィンドウのカードリスト
          • データベース/レギュレーションのカードリスト
          • 上記以外のカードリストにおいては、デフォルトプリセットは適用されません(要望があれば変更するかもしれません)。
    • 仕様変更
      • ソートボタンが存在するカードリストにおいて、「初期ソート」の設定を削除しました。
        • 「初期ソート」の指定は無効になるため、利用していた場合は、上記「デフォルトプリセット」を改めて指定してください。
      • データベース/レギュレーションにおいて、メインカードリストに対するソートの指定を、右側の指定カードリストにも反映するようにしました。

      • デッキ/カードリストにおいて、カードリストをテキストとしてクリップボードに送る機能を追加しました。
      • デッキ/スモワ:デッキ内において、辺の文字サイズを個別に指定できるようにしました。
      • 統計/テーブルビューにおいて、セル内容を%で表示する際、その小数点以下の桁数を指定できるようにしました。
    • 仕様変更
      • アップデートを適用した際、直後の起動時にその旨を表示するようにしました。
      • メインウィンドウにおいて、右上にあった「オンラインマニュアル」と「アプリの更新」ボタンを「ヘルプボタン」に統合し、それをクリックした際に現在のアプリバージョンも確認できるようにしました。

  • Version 1.0.1 (2024/02/19)
    • 不具合修正
      • デッキ/カードリストでの名前欄の編集において、「一度でも改行を指定すると改行の指定を解除できなくなる」不具合を修正しました。
    • 仕様変更
      • デッキ/カードリストでの名前欄の編集において、改行(Enter)以外のテキスト編集を受け付けないようにしました。
