統計>統計表

カードを性質ごとに分けて表で確認できる機能です。

説明

要素をクリックすると説明が表示されます。

表の見かた

  • 「Total」のすぐ右には、サーチバーの検索条件に適合するカードの総数が表示されます。
    • 上の画像では「14252」と表示されていますが、これはこの表の内容が14252種類のカードから作成されていることを示します。
  • 1行目及び1列目には、それぞれの特徴に当てはまるカードの総数が表示されます。
    • 例えば上の画像で「戦士族」の直下にある「1161」のセルは、全カード14252種類のうち「戦士族のモンスターカード」が1161種類あることを示しています。
    • 例えば上の画像で「地属性」のすぐ右にある「2079」のセルは、全カード14252種類のうち「地属性モンスターカード」が2079種類あることを示しています。
  • それ以外の各セルには、各行と列の特徴を併せ持つカードの枚数が表示されます。
    • 例えば上の画像で「戦士族-地属性」のセルには「394」と表示されていますが、これは全カード14252種類のうち「戦士族・地属性のモンスターカード」が394種類あることを示しています。
  • セルをクリックするとそのセルの具体的なカード内容を確認できます。
    • カード名にマウスカーソルを合わせると、その詳細が表示されます。
