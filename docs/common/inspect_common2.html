手札検証の詳細

  • 手札検証は以下の手順で実行されます。
    1. 結果リスト(結果オブジェのリスト)を空にする。
    2. デッキをシャッフルする。
    3. デッキの上から「手札枚数」で指定された数だけカードを取り、手札にする。
    4. 手札内容を検証する。
      • 結果オブジェは以下の情報を保持する。
        • 適合した条件のリスト
        • 「Value 1」「Value 2」それぞれの合計
      1. 「条件リスト」の上から条件項目を見る。
      2. この条件と同じグループの条件が既に結果オブジェの条件リストに含まれている場合は何もしない。
      3. 現在の手札内容がこの条件の「手札リスト」の内容に適合するか確認し、適合した場合以下の処理を行う。
        • 結果オブジェの条件リストにこの条件を追加する。
        • 結果オブジェの「Value 1」「Value 2」にこの条件のそれぞれの値を足す。
    5. 手札にドローソース(各種〈壺〉など)が含まれている場合、その処理を行う。
      • 「ドローソース優先度」の上から、それぞれのカードが手札にあるかを確認する。
      • 《強欲な壺》などのドローを行うカードがある場合
        1. デッキの上から1枚(《強欲な壺》などは2枚)を手札に加える。
        2. メインフェイズ1開始時にしか発動できないカードは手札から取り除く。
        3. 新たな手札の内容を検証する。
        4. 新たな検証の結果オブジェの「Value 1」が現在の結果オブジェのそれより大きい(同じ場合は「Value 2」がより大きい)場合、大きいほうを新たな検証の結果とする。
      • 《強欲で謙虚な壺》などのデッキの上から数枚めくってそのうち1枚を選ぶカードがある場合
        1. デッキの上から指定枚数を取り出す。(デッキからは取り除く)
        2. 取り出したカードのうち1枚を手札に加える。
        3. メインフェイズ1開始時にしか発動できないカードは手札から取り除く。
        4. 新たな手札の内容を検証する。
        5. 2. から 4. を、取り出したカード全てについて行う。
        6. 新たな検証の結果オブジェたちと現在の結果オブジェで「Value 1」を比較し、最も大きかったもの(同じ場合は「Value 2」が最大のもの)を、新たな検証の結果とする。
      • 以上の手順を手札に使用可能なドローソースがなくなるまで繰り返す。
    6. 最終的な検証結果を結果リストに追加する。
    7. 2. から 6. を「試行回数」だけ繰り返す。
    8. 最終的な結果リストの内容を結果欄に表示する。
